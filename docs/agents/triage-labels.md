# Triage Label Vocabulary

Canonical triage roles for work items in this repository:

| Label | Role & Purpose |
|---|---|
| `needs-triage` | Newly filed item, waiting for initial categorization and brief |
| `needs-info` | Blocked on user clarification, trade-off choice, or missing requirements |
| `ready-for-agent` | Clear scope, approved spec/test spec, ready for an AI agent to execute via TDD |
| `ready-for-human` | Requires human decision, manual credential setup, or visual design sign-off |
| `wontfix` | Out of scope, violates Kailash Nadh simplicity, or violates SEBI guardrails |
